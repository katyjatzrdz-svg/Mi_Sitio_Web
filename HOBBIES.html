Resumen

Cantar

Es la actividad de producir sonidos musicales con la voz. Puede ser acompañado de melodías, ritmos y armonías.
 El canto se utiliza en muchas culturas como forma de expresión, entretenimiento o comunicación.
 Es una habilidad que se puede practicar, desarrollar y mejorar, tanto de forma individual como en grupo.

Bailar

El baile es una forma de expresión corporal que sigue ritmos y movimientos, generalmente acompañados de música.
 Se realiza tanto en situaciones recreativas como ceremoniales, y existen muchos estilos, como el ballet,
 la danza moderna, la salsa o el flamenco. Es una actividad que promueve la coordinación, el equilibrio y
 la flexibilidad.

Dibujar

Dibujar es el acto de crear imágenes o representaciones gráficas mediante herramientas como lápices,
 carboncillos o bolígrafos sobre una superficie. Se utiliza para expresarse artísticamente, para crear
 planos, ilustraciones o representaciones visuales de ideas. El dibujo puede ser realista o abstracto y
 es una habilidad que se puede desarrollar con la práctica.

Pintar

Pintar implica aplicar colores sobre una superficie usando pinceles, brochas o esponjas, y puede hacerse
 con diversas técnicas, como acuarela, óleo o acrílico. Esta actividad se utiliza para crear obras artísticas,
 decorativas o ilustrativas. El proceso de pintar permite transmitir emociones, pensamientos y visiones a través
 de colores y formas.
